# Guía de Programazioa aportada por el propietario

Referencia: «AABD 1. Erronka: Azterketa Prestatzeko Gida», texto facilitado en el chat. Describe una convocatoria de febrero y menciona junio; se usa para orientar el formato y las competencias, sin cambiar el calendario de noviembre indicado por el propietario.

- Teoría: 3 puntos, 30 preguntas a/b/c/d, fallos penalizados, sin apuntes ni ordenador. Prioridad: entender POR QUÉ y PARA QUÉ se usa cada tecnología. No se conoce el coeficiente de penalización; no se inventa una nota.
- Práctica: 7 puntos, contexto nuevo y CSV sucio, resolución en Jupyter Notebook. PDF locales de clase permitidos; sin internet ni asistentes IA. Los comandos e imports de consulta no deben memorizarse.
- Competencias: comprensión de listas para nombres de columnas; filtros/nulos con Pandas sin sklearn; Pipeline de preprocesamiento y modelo; class_weight='balanced' justificado; recall, classification_report y confusion_matrix interpretados; BaseModel y @field_validator para validar entradas.

## Ruta principal propia de estudio

P28–P34: lectura completa → limpieza → análisis/desbalance → cinco pasos ML → pesos/métricas → validación → simulacro con otra planta y otros valores. Cada caso contiene el CSV sintético entero, starter con imports, criterios, referencias, ayuda y solución comprobada. CSV y notebook de inicio se descargan desde el caso. No son enunciados atribuidos al profesor ni datos industriales reales.

Las cinco preguntas de ejemplo facilitadas se conservan en la interfaz con sus opciones y explicaciones: Java/Big Data (C), MCP (B), Figure/Axes (B), dropna (C) y carga del modelo al iniciar una API (B). Son cinco ejemplos, no se presentan como un examen oficial de treinta preguntas.

Los ejercicios anteriores se conservan como complementos, con sus IDs y borradores. Todas las materias se ordenan en cinco dificultades estimadas: fácil, básico, intermedio, difícil y muy difícil. La guía 3+7 se asigna solo a Programazioa; no altera los temarios de las otras cuatro asignaturas.

Para simular las condiciones reales, prepara las librerías antes y usa el notebook en local sin internet. El botón web Ejecutar Python es entrenamiento; su primera carga necesita descargar el runtime.
